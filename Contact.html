Snake help

I need someone to relocate a snake

Search the public directory by state and city. Choose a volunteer and send that person a text with the location and a safe-distance photo if available.

  • Do not send the request to the administrator email.
  • Availability and response times are not guaranteed.
  • The website cannot see or manage your conversation.

Listing update

I moved or changed my phone number

Submit the volunteer form again and select “I'm already listed, but need to update my information.” Enter all current information, not only the field that changed.

  • Do not apply as a first-time volunteer again.
  • An administrator will review the update.
  • The approved update will replace the existing public listing.

Listing removal

I want my listing removed

Email the administrators from the address you normally use and identify the exact public listing. Include:

  • Your full name as shown
  • Your listed phone number
  • Your listed city and state
  • A clear request to remove the listing

Listing concern

I need to report a public listing

Email the administrators with enough information to identify the listing and understand the concern. Include:

  • The listed name, phone number, city, and state
  • A factual description of what happened
  • The date of the interaction
  • Relevant screenshots or records, if available

How listing updates work

Use the same process for a new phone number, a move, a name correction, or another significant change.

  1. Submit the formSelect the option stating that you are already listed and need to update your information.
  2. Administrator reviewAn administrator compares the request with the existing record and checks that the required information is present.
  3. Public listing updateAfter approval, the existing listing is updated. The directory does not intentionally create a second active listing.

Privacy reminder: Do not email Social Security numbers, government identification, medical records, account passwords, or other sensitive information. The volunteer form only needs the information requested for the directory listing.

Snakebite or immediate danger

If a snake bites someone, seek emergency medical attention immediately. Do not wait for an email response or a directory volunteer. Do not drive yourself if the bite may make you dizzy or cause you to pass out.

Do not try to catch or kill the snake for identification. If it can be done safely, take a photo from a distance. Read the CDC snakebite guidance.
